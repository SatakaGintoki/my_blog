# Kuronya 的博客设计

## 已确认的方向

2026-10-11，用户从十种风格中偏好瑞士网格、像素档案与杂志分栏，随后确认以「杂志网格」为主，并采用杂志分栏小样中的衬线主文章标题、斜线图文块与短摘要。本次前台已据此实现。

- 整体：按用户提供的「杂志网格」截图配色，使用近白底色（#fdfdfc）、炭灰标题（#24262a）、中性灰正文和柔和蓝色强调（#55778e）。用户明确将背景更正为点阵：24px 间距、低对比小圆点，深色主题使用独立配色。点阵由静态 CSS 渐变绘制，不增加图片、脚本或动画。保留杂志布局，无头像、立体宣传图或全屏背景动画。
- 刊头：昵称用 Inter 大字、统一对齐和粗分隔线建立识别；一句话介绍与关于、归档入口位于下方。后台个人介绍首段仍可显示在首页。
- 主文章：未筛选的首页第一页展示最新发布文章，使用宋体 / 衬线标题、日期、斜线图文块、摘要与阅读链接。短冒号标题可在冒号处换行，避免不平衡断句。
- 图文块：使用 CSS 绘制，不加载图片。默认呈现 STRUCTURE / BEFORE / DETAILS.；前端与问题记录主题使用相应词组。图文块是装饰，辅助技术忽略它，不替代文章标题。
- 次文章：主文章右侧按双列排布，显示编号、分类、日期、标题和摘要。主文章从次文章列表中移除，避免重复；编号依据当前页文章顺序计算。
- 筛选与分页：分类、标签、搜索或后续分页采用常规文章网格，不再突出主文章。没有发布内容时只显示真实空状态，不插入示例。
- 文字：正文使用自托管 Inter 与 Noto Sans SC，标题优先使用系统 Georgia / 宋体。Windows 与 macOS 有系统衬线字体，其他设备可回退到已有中文字体；本轮没有增加字体或图像资源。
- 动效：刊头、主文章和文章条目进入视野时轻轻上移并渐入；悬停时箭头微移、主文章斜线轻移。尊重系统减弱动态效果，内容可直接显示。

## 全站统一

首页、文章列表、归档、关于、正文、搜索弹窗、评论表单、空状态与 404 均使用同一套配色和控件。归档与关于页增加小型栏目标签和刊头分隔线；归档年份用轻量数字排列，404 使用纯文字标识。

登录、管理概览、文章管理、写作编辑、评论审核、分类标签和站点设置也使用近白 / 炭灰 / 柔蓝配色、点阵背景与杂志分隔线。后台侧栏采用文字字标，去除小猫头像与装饰。概览数字按分栏展示，编辑和设置保持实色操作面板，避免点阵干扰输入。个人介绍预览使用与首页相同的昵称样式。登录页呼应首页的斜线图文块，管理标题有轻微入场动画，仍尊重系统减弱动态效果。

颜色、点阵、衬线字体与动画曲线统一定义在 `src/styles.css`，前台布局在 `src/journal.css`，后台布局在按需加载的 `src/admin.css`。深浅主题同时覆盖前台和后台，没有新增字体、图片或第三方依赖。

## 桌面与阅读

首页外宽最大 1112px，扣除内边距后约 1064px，主文章与次文章的列比例为 0.9 : 1.1，间距 40px，图文块宽高比为 2.6。首页次文章标题 19px，文章索引外宽 1040px，双列间距 56px，标题 22px、摘要 14px。数量放在页标题旁，分类日期两端对齐；次文章摘要最多展示三行，标题保留完整内容，短中文冒号前缀尽量保持完整并在冒号后提供换行位置，较长前缀仍可自动换行。900px 以下，首页次文章收为单列，640px 以下全页纵向排列。

正文外宽 760px，实际阅读列约 712px，字号 17px、行距 1.9，手机正文 16px。代码字号桌面 14px、手机 12px，表格 15px；后台和关于页字号独立保留。1280px 以上目录位于正文右侧留白，可折叠，较窄窗口中放在正文前。文章条目和主文章的悬停反馈也用于键盘聚焦。

文章仍使用独立链接阅读；标题改为衬线以呼应首页，正文、代码高亮、表格、锚点和审核评论继续保留。后台写作、Ctrl / Cmd + S 保存、草稿备份、并发保护与个人介绍实时预览继续使用原有实现。

## Markdown 阅读

用户明确希望改善代码、表格、引用和图片的阅读质感。本轮保持现有杂志风格，正文、关于页、后台文章预览与个人介绍预览统一使用经过清理的渲染结果和 `src/markdown.css`。

- 代码：使用更明确的蓝色边线和工具栏，浅色为清透蓝灰底，深色为藏蓝编辑器底。高亮区分紫色关键字、绿色字符串、橙色数字、蓝色函数名、洋红类型和青色属性，注释使用独立灰色和斜体；深浅主题各有配色。语言栏、复制按钮与独立代码区域保留，复制保留代码原文，成功或失败都有反馈，长代码可在块内横向滚动。高亮仍按需加载，未支持的语言保留纯文本。
- 表格：完整阅读列宽度、清晰表头和细线，宽表格在自身区域滚动；支持键盘聚焦及横向滚动，不撑开页面。
- 引用与列表：引用使用柔蓝背景与左侧标记，列表和嵌套列表采用相应间距，行内代码增加轻边框。
- 标题：稳定且不重复的章节 ID、悬停或键盘聚焦时显示的定位链接，正文与侧边目录共享 ID。
- 图片：独立图片由语义化图文块展示，替代文本作为说明；懒加载，点击或键盘激活后放大，Esc / 关闭按钮关闭并恢复焦点。带链接的图片保留原链接行为。

原始 HTML 继续禁用，生成内容仍经 DOMPurify 清理，代码与图片说明中的 HTML 作为文字处理。本轮未增加第三方依赖或字体。预览示例图由 SVG 绘制，仅用于检查图片排版，默认生产构建会一并移除。

## 参考与素材

本轮主要依据用户选择的自制风格小样与用户提供的截图。此前阅读了 [Anthony Fu](https://antfu.me/) 的字体、正文与入场源码，保留其清晰的阅读节奏；最终首页构图以用户新选择的杂志网格为准。

此前生成的头像保留在 `design-assets`，不进入部署包。页头现在为文字标识。字体 OFL 许可证保留于 `public/fonts`。`/preview` 是开发环境的只读示例；生产默认禁用，不写入正式数据库。
